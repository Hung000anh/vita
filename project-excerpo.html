Excerpo

Automated multi-platform text/novel extractor and downloader tool.
(Latin for "extract", "gather") A powerful browser extension specifically designed to automatically collect text and novel contents from leading reading websites.

  • Multi-platform: Supports scanning and downloading from a wide range of online reading platforms grouped by country:
    • China (Simplified): 17k, 22biqu, 23qb, 52shuku, 69shuba, 69shumi, biquge, xbiquge, bookqq, fanqienovel, hetushu, ihuaben, ixdzs8, jjwxc, novel543, powanjuan, qidian, shubaow, shuhaige, uukanshu, xbanxia.

    • US / Global: ao3, cardboardtranslation, fictionpress, foxaholic, freewebnovel, lnmtl, noveldex, novelight, novellunar, royalroad, scribblehub.
    • Turkey: fenrirscans.
    • Russia: ranobelib.
    • Brazil: centralnovel, phoenixnovels.
    • Indonesia: meionovel, novelgo, wbnovel.
    • France: chireads.
  • Auto-Bypass Rate Limit & Captcha: Integrated background OCR (Tesseract.js) to read captchas during data crawling, alongside a smart delay algorithm to avoid IP blocking.
  • Background Multithreaded Download: Operates independently via Service Worker in the background. You can browse websites normally or close tabs; the tool will patiently download thousands of chapters without failure.
  • Flexible File & Format Customization: Allows extracting to standard text format .txt, Word documents .docx, or lightweight .epub e-books. Fully supports dynamic filename patterns using keys like {index} and {title}.

ðŸ“– How to Use

1. Paste Novel Link

Go to the source site, copy the novel details page URL. Paste it into the input box on Excerpo and click Submit.

2. Get Chapter List

After the extension scans the novel metadata, click Get chapter list to fetch and show all chapters.

3. Start Background Download

Select chapters you want to download (or use Quick select box by typing range, e.g. 1-50, 60-70), and then click Download selected chapters (Background).

4. Manage Queue

Track the progress of multithreaded downloads for each chapter in the Queue tab (ðŸ“‹). You can stop or cancel the job at any time.
