Memoria

An all-in-one browser side panel that combines translation, OCR text recognition, quick notes, clipboard history, smart reminders, live weather, and a built-in AI chat assistant.

View on GitHub

✨ Key Features

🤖 Memoria AI Chat

Integrated with Gemini API. Supports automatic key rotation when rate limits are reached and uses your clipboard history as context.

🌐 Translation & History

Quickly translate text within the side panel or directly on any web page. Automatically saves translation history and provides a side-by-side view (Original - Translated).

📷 Screen OCR Translation

Press Alt + S to capture a specific screen area, extract text from images (powered by Tesseract.js Offscreen), and translate it instantly.

📋 Clipboard History

Track and search through copied text, including website sources, and export context to the AI.

📝 Notes Manager

Create and edit Markdown-supported notes, secured with a personal passcode.

⏰ Timers & Reminders

Set recurring alarms, play audio notifications, and manage visual task reminders.

⌨️ Keyboard Shortcuts

Shortcut Command / Function Description
Alt + Q Open Memoria Quickly open the Memoria Side Panel
Alt + A Open AI Chat Open the Side Panel and navigate directly to the Chat tab
Alt + W Open Translation Open the Side Panel, switch to the Translation tab, and focus the input field
Alt + S Trigger OCR Activate screen-capture mode for OCR and translation

📦 Installation

  • Clone or download the source code:
    git clone https://github.com/Hung000anh/memoria.git
  • Open your browser (Chrome / CocCoc / Edge / Brave).
  • Navigate to the extensions management page: chrome://extensions/
  • Enable Developer mode.
  • Click Load unpacked and select the downloaded source code folder.
  • Done! Click the Memoria icon on your toolbar to start using it.

🔑 API Configuration

  • Register for a free API Key at Google AI Studio.
  • Right-click the Memoria icon and select Options (or open Settings within the extension).
  • Enter your Gemini API Key and click Add Key.
  • Tip: You can add multiple keys to let the system automatically rotate them if one encounters rate limits.
